# Q版像素人物 Prompt 测试方案

> 目标：找到最适合拼豆图纸的 Q 版像素风格 prompt
> 测试方法：同一张参考图，用不同 prompt 各生成 1 张，对比效果

---

## 一、测试前准备

### 需要的东西
- 1 张真人照片（上半身/全身，光线好，正面）
- 火山方舟 API Key
- 启动服务，打开网页

### 测试模型
先用 `doubao-seedream-4-0-250828`（免费额度多，0.2元/张）
效果好再试 5.0 lite

---

## 二、5 套 Prompt 对比测试

### 测试方法
用同一张参考照片，依次试下面 5 套 prompt，记录每套效果。
在 chibiGenerator.js 的 `customPrompt` 输入框里粘贴额外描述词，或者直接改 prompt 测试。

---

### Prompt 1: 萌系像素风（默认，最推荐）

**完整 prompt：**
```
像素风格Q版卡通人物，16-bit复古游戏画风，马赛克格子质感，
低分辨率像素艺术，软萌可爱，大头娃娃，2头身比例，圆润造型，
超级大眼睛，小鼻子，粉嫩腮红，
自然站立姿势，正面全身像，纯白色背景，
精致像素画，高完成度，治愈系
```

**预期效果：**
- 像素感强，马赛克格子明显
- 大头大眼，软萌
- 适合直接转拼豆

**关注点：**
- 像素格子够不够明显？
- 比例是不是 2 头身？
- 腮红有没有？
- 背景是不是纯白？

---

### Prompt 2: 贴纸 Q 版（简约干净）

**完整 prompt：**
```
Q版卡通人物，可爱贴纸风格，简约插画，圆润造型，大头小身，
2头身比例，大大的圆眼睛，小嘴巴，粉嫩腮红，
全身立绘，纯白色背景，扁平化设计，干净简洁，精致可爱
```

**预期效果：**
- 没有像素感，是平涂插画风格
- 干净清爽，像贴纸
- 颜色比较少，适合拼豆

**关注点：**
- 颜色是不是平涂（没有渐变）？
- 线条清不清楚？
- 整体是不是很干净？

---

### Prompt 3: RPG 角色风（复古游戏感）

16-bit像素艺术风格角色，复古RPG游戏人物，像素化，马赛克效果，

**预期效果：**

- 颜色数量有限

**关注点：**
- 像素感够不够强？
- 像不像 RPG 游戏里的角色？
- 颜色数量是不是适合拼豆？

## 三、图生图 vs 文生图 对比

### 方式 A: 图生图（使用参考照片）
- 勾选"使用照片参考"
- 生成的人物会参考照片的发型、服装、姿态
- 优点：和本人更像
- 缺点：可能被照片限制，不够 Q 不够萌

### 方式 B: 文生图（不使用参考照片）
- 取消勾选"使用照片参考"
- 完全靠 prompt 文字描述生成
- 优点：风格更统一，更 Q 更萌
- 缺点：和本人不像

**建议：** 先试方式 A，如果不够 Q 不够萌，再试方式 B。
如果方式 B 效果好但不像本人，可以在 customPrompt 里加特征描述（比如"黑长直"、"戴眼镜"、"粉色连衣裙"）。

## 四、效果评分表

每生成一张，按下面几个维度打分（1-5 分）：

| 维度 | 说明 | 权重 |
|------|------|------|
| 可爱度 | 够不够萌，丑不丑 | ⭐⭐⭐⭐⭐ |
| 像素感 | 马赛克格子明不明显 | ⭐⭐⭐⭐ |
| 像本人 | 和参考照片有多像 | ⭐⭐⭐ |
| 颜色干净 | 颜色是不是简洁，适合拼豆 | ⭐⭐⭐⭐ |
| 线条清晰 | 轮廓是不是清楚 | ⭐⭐⭐⭐ |
| 背景纯白 | 背景干不干净 | ⭐⭐⭐ |
| 全身完整 | 是不是完整的全身像 | ⭐⭐⭐ |

### 及格线
- 可爱度 ≥ 4 分（核心！不萌就没意义）
- 颜色干净 ≥ 4 分（不然转拼豆会很杂）
- 线条清晰 ≥ 4 分（不然转拼豆会糊）

## 五、效果不好怎么办？调整技巧

### 问题 1: 不够可爱 / 太写实

**加这些词试试：**
- 超级可爱
- 软萌
- 萌系
- 治愈系
- 圆润
- 大头娃娃
- 超大眼睛
- Q版比例

### 问题 2: 像素感不够 / 太像插画

**加这些词：**
- 像素艺术
- 8-bit / 16-bit
- 马赛克格子
- 低分辨率
- 有限色板
- 像素化
- 大块像素

**去掉这些词：**
- 精致（会让细节变多，像素感减弱）
- 高完成度
- 插画

### 问题 3: 和本人不像

**方法：**
1. 勾选"使用照片参考"
2. 在 customPrompt 里加具体特征：
   - 发色：黑色头发 / 棕色头发 / 金色头发
   - 发型：齐刘海 / 双马尾 / 长卷发 / 短发
   - 服装：白色连衣裙 / 蓝色卫衣 / 粉色外套
   - 特征：戴眼镜 / 有耳环 / 戴帽子
3. 试试 5.0 lite 模型（对参考图理解更好）

### 问题 4: 背景不干净 / 有杂物

**加这些词：**
- 纯白色背景
- 简单背景
- 干净背景
- 孤立的（isolated）
- 无背景

**或者：**
- 生成后用"忽略边缘白色"功能裁剪
- 或者手动把背景涂白

### 问题 5: 颜色太复杂 / 渐太多

**加这些词：**
- 平涂上色
- 有限色板
- 硬边缘
- 无渐变
- 简洁配色
- 纯色填充

### 问题 6: 比例不对 / 头不够大

**加这些词：**
- 2头身比例
- 头很大
- 身体很小
- 大头小身
- Q版比例
- SD比例
- chibi

## 六、进阶：多图生成选最好的

Seedream 4.0+ 支持一次生成多张（最多 15 张）。
可以一次生成 3-4 张，选最好的一张。

**优点：**
- 省时间（一次生成多张比一张张快）
- 有选择余地
- 容易出惊喜

**缺点：**
- 多花钱（按张数算）
- 生成时间更长

如果效果一直不稳定，可以考虑一次生成 3 张选最好的。
3 张也才 0.6 元，比反复试错更高效。

## 七、最终推荐组合（基于测试结果预期）

### 最适合拼豆的组合（预测）

```
模型：doubao-seedream-4-0-250828
风格：萌系像素风（Prompt 1）
图生图：开启
尺寸：1024x1024
```

**理由：**
- 像素感强 → 转拼豆效果好
- 颜色相对少 → 色板匹配容易
- 轮廓清晰 → 拼豆颗粒分明

### 如果像素风效果不好

试试贴纸 Q 版（Prompt 2）+ 预处理像素化：
1. 用贴纸 Q 版生成（平涂插画风格）
2. 用你现有的"图片预处理"功能像素化
3. 再转拼豆

这样像素大小你可以自己控制，效果更稳定。

## 八、快速测试命令（curl）

不想开网页也可以直接用 curl 测试：

```bash
curl --location "https://ark.cn-beijing.volces.com/api/v3/images/generations" ^
--header "Content-Type: application/json" ^
--header "Authorization: Bearer 你的API_KEY" ^
--data "{\"model\":\"doubao-seedream-4-0-250828\",\"prompt\":\"像素风格Q版卡通人物，16-bit复古游戏画风，马赛克格子质感，软萌可爱，大头娃娃，2头身比例，超级大眼睛，粉嫩腮红，长卷发，连衣裙，自然站立姿势，正面全身像，纯白色背景，精致像素画，治愈系\",\"size\":\"1024x1024\",\"response_format\":\"url\",\"watermark\":false}"
```

返回的 url 复制到浏览器就能看效果。
