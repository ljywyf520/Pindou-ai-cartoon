# 十三拼豆坊：拼豆图纸转换器

纯前端、本地浏览器运行的拼豆图纸转换器。图片不会上传到服务器，像素处理、色板匹配、图纸渲染和导出都在当前浏览器完成。

## 启动

在 `拼豆网页/studio` 目录执行：

```powershell
node server.cjs
```

访问 <http://127.0.0.1:4174/studio/>。也可以双击启动脚本，脚本会自动启动 4174 端口并打开页面。

## 新增功能使用

- 上传图片后，在原图卡片和图纸卡片底部使用 `− / ＋ / 重置` 缩放；普通滚轮用于上下滚动，按住 Ctrl/Cmd + 滚轮才缩放；也可以按住鼠标左键或手指拖动画布平移。两张画布都支持横向、纵向滚动条，大图纸不会被截断。
- 图纸卡片上方切换 `彩色颗粒` 和 `打印图纸`。这只是 Canvas 重绘，不会再次调用转换算法。打印模式使用固定大格子，每一个像素格都会显示色卡原始色号，图纸过大时在画布容器内滚动查看。
- 图纸卡片下方的 `色卡用量` 会列出本次实际使用的色号、颜色和数量；点击 `复制色卡清单` 可复制文本清单。
- 色卡用量面板顶部有一条拖拽把手，可上下拖动调整面板高度；点击 `收起` 可只保留标题栏，把更多空间还给图纸预览。
- 手机端原图和图纸会自动按屏幕宽度适配并上下排列；首次打开即可完整看到，点击底部缩放按钮或按住 Ctrl/Cmd 滚轮放大后，可在卡片内滚动查看细节。
- 生成图纸后默认进入“打印图纸”视图，每个方格显示对应色卡的完整 `code` 色号；“彩色颗粒”视图仍保留为不显示文字的效果预览。编号来自 `palette.js` 的色卡对象，不使用数组下标。
- 色号统一读取色板颜色对象的 `code` 字段，格式为用户色卡原始的字母前缀 + 数字（例如 `A1`、`B11`、`H7`）；打印图纸、统计面板、复制文本、PNG 清单和 CSV 使用同一份完整色号。缺少 `code` 时才回退数字索引。
- `palette.js` 已替换为用户提供的 MARD 色卡（220 个实体色块，H1 透明色不参与实色匹配），白色背景为 H2，避免旧版近似色造成色差。
- 为减少色差，原图进入 bear-code 前不再额外提高对比度和饱和度；颜色容差仍映射到安全的 `0~2` 区域合并阈值。
- 颜色容差滑块会映射到安全的 `0~2` 区域合并阈值；默认值不合并相邻区域，只有滑块推到较高位置才轻微合并。直接把 UI 的 `12`、`24` 等数值传给 bear-code 会让浅肤色和浅棕色被错误合并成白色。
- 左侧 `图纸外观` 可设置边框、水平镜像和垂直翻转。它们只改变前端渲染结果，不改变底层网格数据。
- 生成后在页面底部勾选 `导出时拼接色卡清单`，再分别导出彩色效果图 PNG 或打印图纸 PNG；`导出 CSV` 可保存色号和颗粒数量表格。
- 网格线开关、格内色号开关、图纸尺寸提示、2.6 mm / 5 mm 规格、所有原有色板和转换参数均保留。

## 对接 bear-code

页面从 `../bead-core-main/dist/index.js` 引入 `runPipeline`、`prepareSourcePixels`、`computeColorStats` 和 `countTotalBeads`。

`app.js` 的 `generate()` 中明确标记了接入位置：

```js
// 【此处接入bear-code项目转换接口函数】本次迭代只调整前端渲染，底层 bear-code 的 runPipeline 调用保持不变。
const result = runPipeline(pixels, imageWidth, imageHeight, options)
```

本次迭代没有修改 `bead-core-main` 下的任何算法文件。前端结果适配层同时兼容当前仓库的 `{ grid, width, height }` 返回值，以及外部 bear-code 构建产物可能提供的 `{ pixelGrid, palette, colorStats, width, height }` 返回值。若存在 `colorStats`，统计面板直接遍历它，不做二次过滤；若只有当前 `grid`，才使用现有公开统计函数做兼容统计。

渲染时像素格子值只作为调色板索引，先通过 `palette[index]` 取得颜色对象，再读取 `.code` 和 `.hex`。复制清单、PNG 拼接和 CSV 均复用同一套 `.code` 读取逻辑，缺少 `code` 时才回退数字索引。

如需换用其他品牌，只需替换 `palette.js` 的 `swatchTable`，保持每行 `色号 #HEX` 格式；不要修改 `bead-core-main` 算法。

## 静态部署

把 `拼豆网页` 整个目录上传到任意静态服务器即可，入口为 `studio/index.html`。服务器需要支持 ES Module 和 `.js` 静态文件访问。不要直接双击 HTML，使用 `server.cjs`、VS Code Live Server 或其他静态服务器启动。
